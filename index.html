In plain language

Bug hunting is 90% tedious work.
HYDRA automates the tedious 90%.

Companies pay hackers (bug bounties) to find security flaws in their apps. Finding one flaw means scanning thousands of pages, reading mountains of code, and testing the same things over and over. HYDRA is a team of AI agents that does that grind for you — then hands you a verified lead with proof attached.

1 What's an "agent"?

A software worker with a job description. Each HYDRA agent is a specialist — one scans networks, one double-checks findings, one writes the final report. They read files, run commands, and talk to each other so you don't have to babysit ten terminal windows.

2 What does it actually do?

Give it a website you're authorized to test. It maps every subdomain, fingerprints the tech, probes for known weakness patterns, verifies what it finds three separate times, and writes everything up with proof-of-concept commands a human can replay.

3 Why "no false positives" matters?

Bounty platforms reject sloppy reports — too many and your account gets banned. HYDRA's Verifier agent exists purely to say "prove it again". If confidence is under 80%, the finding dies before it ever reaches a triage queue.

How a hunt flows through the heads

Each agent hands off to the next. Everything is saved locally, hashed, and traceable.

Maps the attack surface: subdomains, live hosts, tech stack. Tags CDN-shielded targets.

→
VERIFIER

→
REPORTER

Turns confirmed bugs into platform-ready reports with working proof-of-concept commands.

Getting started

From zero to first hunt in five minutes

No build tools, no API-key maze. If you have Linux, macOS or WSL, this works.

Install

One clone, one script. Setup installs opencode itself if it's missing, renders your identity into the config, and places all 989 skills. bash setup.sh --handle you --email you@mail.com runs without a single question.

Pick a model provider

HYDRA speaks to any OpenAI-compatible endpoint — OpenRouter, NVIDIA NIM, LM Studio, ollama. One environment variable: export OPENROUTER_API_KEY=...

Confirm your authorization

Only test targets covered by a bug-bounty scope or ones you own. This is a hard rule baked into every agent — the Recon agent refuses to move until scope is confirmed.

Hunt

Launch opencode, type /hunt target.com, and watch the pipeline work. Findings save locally with hashes; nothing leaves your machine but your own test traffic.

Verify, then report

Feed leads to /verify. Survivors go to /report — out comes a submission-ready writeup with reproducible PoCs. Submit, collect, repeat.

Questions people actually ask

FAQ

Is this legal to use?
Yes — on targets you're authorized to test: your own systems, or assets inside a bug bounty program's written scope. Every agent checks scope before acting, and the repo ships a full disclaimer. Testing random websites without permission is illegal everywhere that has computers.
Will it find bugs fully automatically while I sleep?
No — and be suspicious of anything claiming otherwise. HYDRA automates recon, pattern-matching, verification drudgery and report writing. Judgment — choosing targets, reading business logic, deciding what's worth pursuing — stays with you. Think of it as a very fast junior team you direct, not an autonomous money printer.
Do I need paid API keys?
You need one AI model provider. OpenRouter has free models; ollama runs fully local and free. Everything else — the skills, playbooks, scripts, CI — costs nothing and phones nobody.
What makes this different from just using ChatGPT?
ChatGPT gives advice; HYDRA executes. It runs real scanners against real targets, keeps per-agent memory across sessions, enforces verification discipline, and produces reports in exact platform format. It's a workflow with guards, not a chat window.
Can it break my computer or leak my data?
Findings and reports stay in ~/recon_reports on your machine. The repo's CI blocks secret-shaped content from ever being committed, and GitHub push protection is enabled. As with any tool that executes commands, read what it runs — that habit will serve you well beyond HYDRA.
What if an agent gets stuck or hallucinates?
All seven agents carry a Self-Rescue Protocol: when confused, they fire parallel web searches, fetch primary documentation, cross-verify two independent sources, and log the knowledge gap — instead of guessing confidently. The Debug agent turns every recovered mistake into a permanent prevention rule.
